## 🔬 Research

### Master's Thesis
**A Hybrid Deep Learning Architecture for Software Defect Prediction**

Software defects are expensive, and finding them late is even more expensive. My thesis designs a **hybrid, attention-based deep learning model** that learns from software data to predict which modules are likely to contain defects — helping teams focus testing and review effort where it matters most.

- 🧪 End-to-end pipeline: data cleaning & preprocessing → model design → evaluation
- 🎯 Focus on practical, reproducible results that can be applied in real development workflows
- 📄 Paper in preparation
- 💻 Code: [attention-based-software-defect-prediction](https://github.com/Marziehkazemi1/attention-based-software-defect-prediction)
